DokkanTS Category Helper 1.2.0 can update itself.

- New versions of the app: at most once a day (or an hour after a check that failed), when you open Dokkan or the app, it asks GitHub whether a newer version is out. If there is one, a dot appears on the bubble, the search panel shows a row that takes you to the update, and the app shows what is new in it.
- Update from inside the app: tap Update and the new version downloads from GitHub and, once you confirm, installs over the one you have, keeping your dictionary and settings. The first time, Android asks you to allow installs from this source. Later asks you again the next day.
- What's new: after an update the app shows what changed. You can open it again from Settings, About, under Check for app updates.
- New names: Check for updates is now Update categories. The switch Check for updates automatically is now Check automatically, and it covers both checks, the categories and the app.
